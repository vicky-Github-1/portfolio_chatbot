🤖 AI Portfolio Chatbot

An AI-powered chatbot integrated into a developer portfolio website that allows visitors to interact with the portfolio using natural language. Instead of navigating through multiple sections, users can simply ask questions about the developer, projects, skills, and experience.

The chatbot provides an interactive and engaging way for recruiters and visitors to explore the portfolio.

🚀 Features

💬 Chat-based interaction with the portfolio

👨‍💻 Answers questions about the developer

📂 Provides information about projects and skills

🔗 Shares important links like GitHub and contact details

⚡ Instant responses to user queries

📱 Simple and responsive chat interface

🛠️ Tech Stack

Frontend: React.js

Backend: Node.js, Express.js

AI Integration: Groq LLM API

💡 Example Questions Users Can Ask

"Who are you?"

"What projects have you built?"

"What technologies do you know?"

"Show me your GitHub."

"Tell me about your experience."


⚙️ Installation

Clone the repository:

git clone https://github.com/your-username/portfolio-chatbot.git

Go to the project folder:

cd portfolio-chatbot

Install dependencies:

npm install

Run the server:

npm start
